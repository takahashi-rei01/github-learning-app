GitHub

GitHub Pages更新手順

  1. 新しい index.html を用意
  2. GitHubで既存の index.html を開く
  3. Upload files または鉛筆マークで差し替え
  4. Commit changes
  5. 数分後に公開URLへ反映

Live Server

ソース管理

Codex

依頼の型

目的：
〇〇を追加したい

条件：
・既存デザインを崩さない
・スマホ対応
・index.html 1ファイルで動く

やってほしいこと：
・〇〇タブを追加
・クイズを追加
・変更内容を要約

Claude Code

レビューの型

変更差分をレビューしてください。
確認してほしいこと：
・既存機能を壊していないか
・不要な変更がないか
・スマホ表示で崩れないか
・セキュリティ上問題ないか
